Sobre o projeto

Nosso projeto consiste em uma estação meteorológica baseada em Internet das Coisas (IoT). Ela utiliza sensores para coletar dados do ambiente, como temperatura, umidade e outras condições climáticas, transformando essas medições em informações digitais para acompanhamento em tempo real.

A proposta é unir eletrônica, programação e redes para criar uma solução prática de monitoramento ambiental, acessível e automatizada.

Como a estação funciona

  • Coleta de dados: os sensores fazem leituras das condições do ambiente.
  • Dispositivo IoT: o microcontrolador processa e organiza as informações coletadas.
  • Envio pela rede: os dados são publicados usando o protocolo MQTT.
  • Dashboard: as informações recebidas podem ser visualizadas e acompanhadas.

IoT, MQTT e Mosquitto

A Internet das Coisas (IoT) permite conectar objetos físicos à internet. Neste projeto, a estação envia os dados dos sensores para outros sistemas sem a necessidade de comunicação direta entre todos os dispositivos.

Para essa comunicação utilizamos o MQTT, um protocolo leve e eficiente, ideal para dispositivos IoT. O Mosquitto funciona como o broker MQTT: ele recebe as mensagens publicadas pela estação em tópicos e as distribui para quem estiver inscrito, como o nosso dashboard.

Objetivo do projeto

Desenvolver uma experiência prática de monitoramento meteorológico e demonstrar como a tecnologia IoT pode ajudar na coleta, transmissão e análise de dados ambientais de forma rápida, conectada e escalável.
